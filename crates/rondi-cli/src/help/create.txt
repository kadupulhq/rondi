Usage: rrdtool [options] command command_options
* create - create a new RRD

	rrdtool create filename [--start|-b start time]
		[--step|-s step]
		[--template|-t template-file]
		[--source|-r source-file]
		[--no-overwrite|-O]
		[--daemon|-d address]
		[DS:ds-name:DST:dst arguments]
		[RRA:CF:cf arguments]
